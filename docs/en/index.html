Install / 04

Install.

The farm is for a server or a home computer that stays on. The command line bot is for SteamGifts alone.

  1. Get the code and its dependencies. Needs Python 3.10 or newer.

    git clone -b botfarm https://github.com/PalmaLuv/SteamGiftBot.git
cd SteamGiftBot
python3 -m venv env
env/bin/pip install -r requirements.txt

  2. Set the panel's password and start the farm on your computer's LAN address.

    env/bin/python -m steamgiftbot.farm --set-password
env/bin/python -m steamgiftbot.farm --host 192.168.1.10

  3. Open http://192.168.1.10:8092, sign in and connect a site. A systemd service, the firewall and phones are covered in the README.

The farm lives on the botfarm branch for now, hence -b botfarm. Once it is merged into main, the flag goes.

  1. Download SteamGiftBot.exe and its .sha256 from releases. No Python needed.

  2. Check the checksum against the line in the .sha256 file.

    certutil -hashfile SteamGiftBot.exe SHA256

  3. Run it: the bot asks for the cookie and a few settings. A dry run shows what it would enter without spending anything.

    SteamGiftBot.exe --once --dry-run

  1. Put the SteamGifts cookie (the PHPSESSID value) in a secret file, so that docker inspect does not show it.

    sudo mkdir -p /srv/steamgiftbot
printf '%s' 'PHPSESSID' | sudo tee /srv/steamgiftbot/cookie >/dev/null
sudo chown -R 1000:1000 /srv/steamgiftbot && sudo chmod 600 /srv/steamgiftbot/cookie

  2. Start the container. It does not run as root; the image is built for amd64 and arm64.

    docker run -d --name steamgiftbot --restart unless-stopped \
  -v /srv/steamgiftbot:/app/data \
  -e STEAMGIFTBOT_COOKIE_FILE=/app/data/cookie \
  -e STEAMGIFTBOT_GIFT_TYPE=All -e STEAMGIFTBOT_MIN_POINTS=0 -e STEAMGIFTBOT_PINNED=no \
  ghcr.io/palmaluv/steamgiftbot:latest --config /app/data/config.ini

This is the command line bot, SteamGifts only. The farm runs in Docker with --data; see the README.

FAQ / 05

FAQ.

The short version. The rest is in the README and the wiki.

Can my account get banned?

It can. SteamGifts forbids auto-entry scripts, and other sites have rules of their own. The farm pauses, backs off when a site asks, and never works around Cloudflare or captchas, but the decision and the risk are yours.

Does the farm know my passwords?

No. It signs in with cookies copied from your browser and keeps them on your own computer. The panel never hands them back, not even to you.

Do I need a server?

Any computer that stays on will do: a mini PC, an old laptop, a Raspberry Pi. The farm spends most of its time waiting.

Does the panel work on a phone?

Yes. At home through your computer's LAN address, away through Tailscale. It can be added to the home screen.

Why does the farm enter nothing?

Open the site's dry run: every giveaway has its reason there. Most often the balance ran out or the account level is set wrong.

Is this an official SteamGifts project?

No. SteamGiftBot is an independent open source project under MPL-2.0, not affiliated with SteamGifts, IndieGala, GOG, itch.io or Valve.
