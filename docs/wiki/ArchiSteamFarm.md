# ArchiSteamFarm

[ArchiSteamFarm](https://github.com/JustArchiNET/ArchiSteamFarm) (ASF) —
отдельная программа, которая держит ваши аккаунты Steam в сети. Ферма
обращается к ней через IPC — встроенный API ASF — чтобы:

- **активировать выигранные ключи** в Steam (раздел «Выигрыши»);
- **добавлять в библиотеку бесплатные игры Steam** (площадка
  [Бесплатные игры Steam](Бесплатные-игры-Steam.md)).

Ферма не управляет ASF и не меняет его настройки.

## Настройка

### ASF на этом же сервере

Если ASF лежит в `~/asf`, слушает `http://127.0.0.1:1242` и в
`~/asf/config/ASF.json` задан `IPCPassword`, ничего вписывать не нужно: ферма
прочитает пароль сама. Откройте **Настройки → ArchiSteamFarm** и нажмите
**Проверить ASF**.

### ASF на другом компьютере

1. В `config/ASF.json` того ASF задайте `IPCPassword`.
2. Разрешите доступ к IPC не только с локальной машины. В `config/IPC.config`
   укажите адрес, например `"Url": "http://*:1242"`, и откройте порт в фаерволе
   только для своей сети.
3. В **Настройки → ArchiSteamFarm** укажите «Адрес IPC», например
   `http://192.168.1.20:1242`, и «Пароль IPC». Нажмите **Проверить ASF**.

| Настройка | Что делает |
| --- | --- |
| Адрес IPC | где искать ASF |
| Пароль IPC | `IPCPassword`. Если пусто, ферма берёт его из `~/asf/config/ASF.json` |
| Бот для ключей | имя бота, на которого активировать ключи. Если пусто — первый бот в сети. Ключ можно активировать только один раз, поэтому всегда выбирается один бот |
| Активировать выигранные ключи сразу | как только у выигрыша появляется ключ, ферма отправляет его в ASF |

Бесплатные игры добавляются **всем** ботам ASF (или только указанному боту).

## Ответы при активации

| Ответ | Что значит | Что делает ферма |
| --- | --- | --- |
| активирован | ключ подошёл, игра в библиотеке | статус выигрыша → «Активирован» |
| уже есть в библиотеке | игра у вас уже была | статус → «Активирован» |
| не для вашего региона | ключ для другого региона | оставляет выигрыш как есть |
| неверный ключ | опечатка или это не ключ Steam | оставляет как есть |
| ключ уже кто-то активировал | ключ использован | оставляет как есть |
| сначала нужна основная игра | это DLC | оставляет как есть |
| это не ключ игры | код кошелька или подарок | оставляет как есть |
| Steam просит подождать | слишком много активаций за час | попробуйте позже |
| бот ASF не в сети / Steam не дал ответа | ASF или Steam недоступны | попробуйте позже |

Результат пишется под ключом в разделе «Выигрыши» и приходит в Telegram.

## Ошибки подключения

| Сообщение | Что делать |
| --- | --- |
| ASF недоступен по адресу … | ASF не запущен, неверный адрес или порт закрыт |
| ASF не принял пароль IPC | пароль не совпадает с `IPCPassword` |
| ASF не пускает этот адрес | в ASF не задан `IPCPassword`, а запрос идёт не с локальной машины |
| в ASF нет ни одного бота в сети | боты отключены или ждут кода Steam Guard — посмотрите веб-интерфейс ASF |
