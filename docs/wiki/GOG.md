# GOG

Несколько раз в месяц на главной странице [GOG](https://www.gog.com/) появляется
баннер раздачи: игру можно забрать бесплатно, и она навсегда останется в
библиотеке GOG. Ферма забирает её сама.

## Подключение

**Площадки → GOG → Подключить**. Войдите на gog.com, обновите главную страницу
с открытой вкладкой Network и скопируйте первый запрос как cURL. Ферма проверит
вход и покажет имя аккаунта.

## Как это работает

Раз в «Проверять раз в» минут (по умолчанию 4 часа) ферма отправляет тот же
запрос, что и кнопка на баннере (`/giveaway/claim`), и смотрит на ответ:

| Ответ GOG | Что значит |
| --- | --- |
| пустой ответ `{}` | игра добавлена в библиотеку. Ферма записывает вход и сообщает в Telegram |
| «Already claimed» | вы уже забрали эту раздачу |
| «Giveaway has ended», 404 | сейчас раздачи нет |
| 401 | GOG больше не узнаёт cookie, нужно [подключить заново](Подключение-площадок.md) |

Название игры GOG в ответе не присылает, поэтому ферма берёт его с баннера на
главной странице. Если баннер прочитать не удалось, в истории будет запись
«Раздача GOG».

## Настройки

<!-- settings:gog -->
**Аккаунт**

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| Cookie | — | gog.com → F12 → Network → F5 → правый клик по первому запросу → Copy → Copy as cURL |
| User-Agent браузера | пусто | из cURL берётся сам |

**Работа**

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| Проверять раз в (мин) | `240` | раздача висит несколько дней, чаще проверять незачем |

**Расписание и лимиты**

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| Часы работы | пусто | например 08:00-23:00 или 09:00-13:00, 18:00-02:00; пусто — круглосуточно. Часовой пояс задаётся в настройках фермы |
| Макс. входов за сутки | пусто | пусто — без лимита |
| Макс. трат за сутки | пусто | в валюте площадки; пусто — без лимита |
<!-- /settings -->

## Учтите

- При получении игры GOG может подписать аккаунт на рассылку. Отписаться можно
  в настройках аккаунта GOG, раздел «Рассылки».
- Вкладка «Что возьмёт» покажет игру, только если баннер раздачи сейчас виден
  на главной странице. Забрать игру ферма пробует на каждом проходе в любом
  случае.
