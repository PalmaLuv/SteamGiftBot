# Бесплатные игры Steam

Иногда Steam раздаёт игры навсегда: игра на время становится бесплатной, и
если добавить её в библиотеку, она останется у вас насовсем. Эта площадка
добавляет такие игры сама.

Сама ферма в Steam не входит: игры добавляет
[ArchiSteamFarm](ArchiSteamFarm.md) (ASF) от имени ваших ботов. Поэтому cookie
этой площадке не нужны, а нужен запущенный ASF.

## Подключение

1. Убедитесь, что ASF запущен и его боты в сети. Если ASF работает на этом же
   сервере с паролем IPC в `~/asf/config/ASF.json`, больше ничего настраивать не
   нужно. Иначе укажите адрес и пароль ASF в **Настройки → ArchiSteamFarm**.
2. **Площадки → Бесплатные игры Steam → Подключить → Проверить подключение.**
   Ферма запросит у ASF список ботов и покажет, какие из них в сети.
3. Выберите набор настроек и нажмите **Сохранить и запустить**.

## Откуда список игр

Ферма берёт открытый список
[ASFinfo](https://github.com/C4illin/ASFinfo) — его же использует плагин
FreePackages для ASF. Это текст, где каждая строка — `a/<appid>` (игра) или
`s/<subid>` (пакет), свежие сверху.

## Как проходит проход

1. Ферма скачивает список и отбирает то, чего ещё не пробовала.
2. Узнаёт в магазине Steam названия игр, чтобы применить фильтры: чёрный
   список, «без DLC», «без 18+».
3. Берёт не больше «Не больше за проход» штук (по умолчанию 20): Steam
   ограничивает число бесплатных лицензий в час.
4. Отправляет их в ASF одним запросом (`AddLicense`) для всех ботов.
5. Каждый результат записывает в журнал. Добавленные игры попадают в историю
   входов.

| Результат | Что делает ферма |
| --- | --- |
| добавлено в библиотеку | записывает вход, больше эту игру не трогает |
| уже есть в библиотеке | больше эту игру не трогает |
| Steam просит подождать или не ответил | попробует на следующем проходе |
| другие отказы | больше эту игру не трогает |

## Настройки

<!-- settings:steamfree -->
**Что брать**

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| Боты ASF | пусто | каждый бот ASF — отдельная учётка Steam; имена через запятую, пусто — все боты |
| Не больше за проход | `20` | Steam ограничивает число бесплатных лицензий в час |
| Чёрный список | пусто | слова через запятую |

**Фильтры**

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| Пропускать игры из моей библиотеки Steam | выкл | нужны Steam API-ключ и профиль в настройках фермы |
| Пропускать DLC, саундтреки, артбуки, паки | выкл |  |
| Пропускать 18+ | выкл |  |

**Работа**

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| Проверять раз в (мин) | `180` |  |

**Расписание и лимиты**

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| Часы работы | пусто | например 08:00-23:00 или 09:00-13:00, 18:00-02:00; пусто — круглосуточно. Часовой пояс задаётся в настройках фермы |
| Макс. входов за сутки | пусто | пусто — без лимита |
| Макс. трат за сутки | пусто | в валюте площадки; пусто — без лимита |
<!-- /settings -->

«Макс. трат за сутки» для этой площадки ничего не значит: игры бесплатные.
«Макс. входов за сутки» работает как обычно.
