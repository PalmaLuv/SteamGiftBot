# Бот для командной строки

Исходный SteamGiftBot: работает только с SteamGifts, без панели и без
сервера. Подходит, если нужна одна площадка или бот должен запускаться по
расписанию на обычном компьютере. Полное описание на английском — в
[README](../../README.md#first-run).

## Первый запуск

```bash
env/bin/python main.py
```

Бот спросит cookie `PHPSESSID` и несколько настроек, сохранит их в
`config.ini` и начнёт работать. Как достать cookie, описано в
[Подключение площадок](Подключение-площадок.md); боту нужно одно значение
`PHPSESSID`.

Сначала стоит посмотреть, что бот будет делать:

```bash
env/bin/python main.py --dry-run
```

Бот пройдёт по сайту как обычно, применит все фильтры и покажет, во что вошёл
бы, ничего не тратя. Это ещё и самый быстрый способ проверить, работает ли
cookie.

## Параметры

| Параметр | Что делает |
| --- | --- |
| `--setup` | открыть меню настроек вместо запуска |
| `--config PATH` | путь к `config.ini` |
| `--no-input` | ничего не спрашивать; если настройки не хватает — выйти с ошибкой |
| `--once` | один проход и выход, без ожидания поинтов; для cron и планировщика |
| `--dry-run` | показать, во что вошёл бы, ничего не тратя |
| `--cookie VALUE` | `PHPSESSID` |
| `--type TYPE` | `All`, `WishList`, `Recommended`, `Copies`, `DLC`, `New` |
| `--min-points N` | не опускать баланс ниже N |
| `--pinned` / `--no-pinned` | входить ли в закреплённые раздачи |
| `--points-wait SECONDS` | сколько ждать поинты (по умолчанию 900) |
| `--max-cost N` | пропускать раздачи дороже N |
| `--max-entries N` | пропускать раздачи, где больше N участников |
| `--level N` | ваш contributor level |
| `--skip-region-locked` | пропускать региональные раздачи |
| `--cards-only` | только игры с карточками Steam |
| `--blacklist WORDS`, `--whitelist WORDS` | слова через запятую |
| `--telegram-token`, `--telegram-chat` | Telegram |
| `--telegram-chat-id` | показать ID чатов, которые писали боту, и выйти |
| `--notify-test` | отправить тестовое сообщение и выйти |
| `--no-telegram`, `--no-check-wins` | выключить Telegram или проверку выигрышей |
| `--log` / `--no-log` | писать ли лог в `log/` |

Любой параметр можно задать и переменной окружения с приставкой
`STEAMGIFTBOT_`, например `STEAMGIFTBOT_COOKIE` или `STEAMGIFTBOT_MIN_POINTS`.
Приоритет такой: параметры командной строки, потом переменные окружения, потом
`config.ini`.

## По расписанию

**cron, раз в 12 часов:**

```
0 */12 * * * cd /путь/к/SteamGiftBot && env/bin/python main.py --once --no-input
```

**Планировщик Windows:**

```
schtasks /create /tn SteamGiftBot /sc hourly /mo 12 /tr "C:\SteamGiftBot\SteamGiftBot.exe --once --no-input"
```

**Docker:**

```bash
docker run --rm -e STEAMGIFTBOT_COOKIE=ваш_PHPSESSID -e STEAMGIFTBOT_GIFT_TYPE=All \
  -e STEAMGIFTBOT_MIN_POINTS=0 -e STEAMGIFTBOT_PINNED=no ghcr.io/palmaluv/steamgiftbot:latest --once
```

## Переход на ферму

Ферма читает тот же `config.ini`, поэтому SteamGifts в ней окажется подключена
сразу, с теми же настройками. Не запускайте бот для командной строки и ферму
одновременно на одном аккаунте: они будут тратить одни и те же поинты.
