# Первый запуск фермы

Здесь ферма запускается вручную, чтобы проверить, что всё работает. Как сделать
так, чтобы она запускалась сама после перезагрузки, — на странице
[Сервер и служба](Сервер-и-служба.md).

## 1. Задайте пароль панели

```bash
env/bin/python -m steamgiftbot.farm --set-password
```

Пароль должен быть не короче 6 символов. В `farm.json` хранится только его
хэш (PBKDF2). Если забыли пароль, выполните ту же команду ещё раз.

## 2. Узнайте адрес компьютера в сети

Панель должна слушать адрес из вашей домашней сети, а не все адреса сразу.

```bash
ip -4 addr show | grep inet        # Linux: ищите 192.168.x.x или 10.x.x.x
ipconfig                           # Windows: «IPv4-адрес»
tailscale ip -4                    # если стоит Tailscale: адрес 100.x.x.x
```

## 3. Запустите ферму

```bash
env/bin/python -m steamgiftbot.farm --host 192.168.1.10
```

| Параметр | Что делает |
| --- | --- |
| `--host` | на каком адресе работает панель. Можно указать несколько через запятую: `192.168.1.10,100.64.0.5`. Если адрес ещё не появился (например, Tailscale при загрузке), ферма будет пробовать каждые 15 секунд |
| `--port` | порт панели, по умолчанию `8092` |
| `--data` | папка для `farm.json`, истории и логов, по умолчанию — папка проекта |
| `--config` | путь к `config.ini`, по умолчанию — в папке данных |
| `--no-autostart` | запустить только панель, все площадки остаются остановленными |
| `--set-password` | задать пароль панели и выйти |

Вместо параметров можно задать переменные окружения `BOTFARM_HOST`,
`BOTFARM_PORT`, `BOTFARM_DATA` и `BOTFARM_PASSWORD`.

> **Не используйте `--host 0.0.0.0` на компьютере с белым IP.** В панели
> хранятся cookie ваших аккаунтов, ей нечего делать в интернете. Чтобы
> заходить в панель вне дома, используйте Tailscale — см.
> [Панель на телефоне](Панель-на-телефоне.md).

## 4. Откройте панель

В браузере на любом устройстве в той же сети откройте
`http://192.168.1.10:8092/` и войдите с паролем из шага 1. Браузер запомнит
вход на 30 дней.

Если страница не открывается, скорее всего, порт закрыт фаерволом. Как его
открыть — в [Сервер и служба](Сервер-и-служба.md#фаервол).

## 5. Подключите первую площадку

**Площадки → Добавить площадку → Подключить**. Мастер подключения по шагам
покажет, что скопировать из браузера. Подробнее — в
[Подключение площадок](Подключение-площадок.md).

Если раньше вы пользовались ботом для командной строки, SteamGifts уже будет
подключена: ферма читает тот же `config.ini`.

## 6. Проверьте, что ферма будет делать

На странице площадки откройте вкладку **«Что возьмёт»**. Это пробный проход:
ферма покажет текущие раздачи и что сделает с каждой, ничего не тратя.

## 7. Остальные настройки

В разделе **Настройки** проверьте:

- **Общее → Часовой пояс.** По нему работают часы работы и время сводки.
- **Telegram.** Ферма будет присылать выигрыши и ошибки; см. [Telegram](Telegram.md).
- **Библиотека Steam.** Чтобы не входить в раздачи игр, которые у вас уже есть.
- **Что запускать вместе с фермой.** Отметьте площадки, которые должны
  стартовать сами.

Всё, ферма работает. Когда соберётесь оставить её работать постоянно, переходите
к [Сервер и служба](Сервер-и-служба.md).
