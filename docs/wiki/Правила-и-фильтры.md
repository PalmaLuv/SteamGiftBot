# Правила и фильтры

Эти правила понимает каждая площадка. Настраиваются они отдельно на странице
каждой площадки, во вкладке «Настройки».

## Часы работы

Поле «Часы работы» задаёт, когда площадка может входить в раздачи. Время — по
часовому поясу фермы ([Настройки → Общее](Настройки-фермы.md)).

| Значение | Что значит |
| --- | --- |
| пусто | круглосуточно |
| `08:00-23:00` | с 8 утра до 11 вечера |
| `9-13, 18:30-02:00` | два окна; второе переходит через полночь |
| `22:00-06:00` | только ночью |

Минуты можно не писать (`9-13`). Окна разделяются запятой или точкой с запятой.

Вне часов работы площадка не тратит баланс и не делает запросов. Она ждёт
ближайшего окна, а на карточке написано: «Вне часов работы, откроется в 08:00».
Если закончились часы работы прямо во время прохода, проход прерывается.
Кнопка «Пройти сейчас» запускает один проход, не дожидаясь часов работы.

## Дневные лимиты

- **Макс. входов за сутки** — сколько раз площадка может войти в раздачи за
  последние 24 часа.
- **Макс. трат за сутки** — сколько можно потратить за 24 часа, в валюте
  площадки (P, iS, OP).

Сутки считаются скользящими: это последние 24 часа, а не календарный день.
Когда лимит исчерпан, площадка ждёт, пока самый старый вход за эти сутки
выйдет из окна. На карточке видно, когда это случится: «Дневной лимит исчерпан,
сброс в 14:20». Ход лимита показывают полоски на карточке.

## Готовые наборы

Набор меняет сразу несколько настроек, остальные не трогает. Каждая площадка
берёт из набора только те настройки, которые у неё есть. Например, у
OpiumPulses нет «порядка», поэтому его набор порядок не меняет.

## Фильтры

### Пропускать DLC, саундтреки, артбуки, паки

Раздача пропускается, если в названии есть одно из этих слов. Совпадение ищется
только по целому слову, поэтому «Backpack Hero» остаётся игрой, хотя внутри
есть «pack».

<!-- words:junk -->
`soundtrack`, `ost`, `original sound`, `artbook`, `art book`, `wallpaper`, `wallpapers`, `dlc`, `season pass`, `expansion pass`, `pack`, `costume`, `costumes`, `skin`, `skins`, `outfit`, `outfits`, `upgrade`, `booster`, `supporter edition`, `cosmetic`

### Пропускать 18+

Слова, по которым игра считается «для взрослых», тоже ищутся целиком:

`hentai`, `nsfw`, `sex`, `sexy`, `erotic`, `erotica`, `lewd`, `porn`, `nude`, `nudity`, `waifu`, `uncensored`, `adult only`, `adults only`, `xxx`, `18+`

### Пропускать игры из моей библиотеки Steam

Для этого фильтра нужны ключ Steam Web API и профиль в
[Настройки → Библиотека Steam](Настройки-фермы.md), а в приватности профиля
Steam «Игровые данные» должны быть «Открытые». Игра сравнивается по номеру в
Steam, а если номера нет — по названию. Список игр ферма обновляет раз в 6
часов. Если Steam его не отдал, фильтр просто не работает: ферма продолжает
входить в раздачи, а причина видна по кнопке «Проверить».

### Чёрный и белый списки

Слова через запятую, регистр не важен, ищется вхождение в название:

- **чёрный список** — пропускать раздачи, в названии которых есть хоть одно
  из слов;
- **белый список** — если задан, брать только раздачи, в названии которых есть
  хоть одно из слов.

Добавить игру в чёрный список можно и кнопкой 🚫 рядом с ней в истории входов
или в «Что возьмёт».

## Сначала игры из списка желаемого

Включается в [Настройки → Библиотека Steam](Настройки-фермы.md). Нужны профиль
Steam и открытый список желаемого; ключ API не обязателен, если профиль указан
как SteamID64.

- **IndieGala** считает игры из списка желаемого приоритетными: они идут первыми
  и могут тратить резерв, если это разрешено.
- **SteamGifts** начинает каждый проход с раздела «Wishlist» самого сайта. Этот
  раздел SteamGifts составляет по вашему списку желаемого Steam.

## Порядок проверки

На каждой площадке раздача проходит три проверки:

1. условия самой площадки: цена, участники, уровень и т. д.;
2. общие фильтры: DLC, 18+, чёрный и белый списки, игры из библиотеки;
3. бюджет: баланс, резерв, дневные лимиты.

Первая же не пройденная проверка становится причиной пропуска. Её видно в
«Что возьмёт» и в строке журнала «Пропущено: …» в конце прохода.
