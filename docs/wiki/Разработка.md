# Разработка

## Как всё устроено

```
steamgiftbot/
  bot.py, filters.py, …   бот для командной строки (SteamGifts)
  farm/
    __main__.py           запуск: параметры, логи, листенеры, автозапуск
    manager.py            FarmManager: farm.json, состояние, сводка, Telegram, ASF
    base.py               Platform: поток площадки, ожидания, лимиты, формы настроек, разбор cookie
    rules.py              фильтры слов, часы работы, библиотека и список желаемого Steam
    steamgifts.py …       по модулю на площадку
    asf.py                клиент IPC ArchiSteamFarm
    telegram.py           команды Telegram (long polling)
    web.py                HTTP-сервер и JSON API на stdlib
    static/index.html     вся панель: одна страница, без сборки
scripts/build-wiki.py     заполняет таблицы настроек в этой вики из кода
tests/                    pytest, без сети
```

**Потоки.** У каждой площадки свой поток (`Platform.loop`). Ещё есть часы
фермы (ежедневная сводка, раз в минуту), поток команд Telegram и по
HTTP-серверу на каждый адрес из `--host`. Площадки не делят сессии между
собой. Пробный проход работает на копии площадки (`Platform.sandbox`) со своей
сессией, поэтому не мешает идущему проходу.

**Ошибки.** Площадка сообщает о проблеме исключениями из `base.py`:

| Исключение | Что делает ферма |
| --- | --- |
| `AuthError` | останавливает площадку, состояние «Нужен вход заново», сообщение в Telegram |
| `PlatformError` | останавливает площадку с ошибкой, сообщение в Telegram |
| `RetryLater` | состояние «Ошибка, повтор», новая попытка через 15 минут |
| любое другое | то же, что `RetryLater`, плюс трассировка в журнал |

## Как добавить площадку

1. Создайте `steamgiftbot/farm/mysite.py` с классом-наследником `Platform`:

```python
from steamgiftbot.farm.base import (Platform, AuthError, RetryLater, buildSession, cookieGuide,
                                    field, grouped, parseCookies, presetFields, scheduleFields)


class MySitePlatform(Platform):
    key, title, unit = 'mysite', 'MySite', 'MP'
    siteURL = 'https://mysite.example/giveaways'
    description = 'Раздачи за MP.'
    category = 'points'              # или 'free'

    def schema(self):                # форма настроек; группы становятся разделами
        return grouped('Аккаунт', [
            field('cookie', 'Cookie', 'secret', help='скопируйте запрос как cURL'),
        ]) + grouped('Работа', [
            field('interval', 'Пауза между проходами (мин)', 'int', 60),
        ]) + presetFields() + scheduleFields()

    def configured(self):
        return bool(self.settings().get('cookie'))

    def guide(self):                 # шаги мастера подключения
        return cookieGuide('MySite', self.siteURL)

    def check(self, values):         # проверка из мастера, без сохранения
        conf = self.trialSettings(values)
        box = self.sandbox()
        box.session = buildSession(None, parseCookies(conf['cookie']), '.mysite.example')
        ...                          # войти, прочитать баланс; AuthError, если не пустило
        return {'account': 'имя', 'balance': 42}

    def preview(self):               # «Что возьмёт»: ничего не тратить
        return {'balance': 42, 'account': '', 'note': '', 'items': [
            {'name': 'Game', 'url': '…', 'cost': 1, 'entries': 10, 'enter': True, 'reason': ''}]}

    def run(self):                   # главный цикл
        while not self.stopped:
            conf = self.gate()       # ждёт часы работы и лимиты; None — остановлено
            if conf is None:
                return
            ...                      # проход: self.ruleReason(), self.dailyLeft(),
                                     # self.recordEntry(name, cost, url), self.pause()
            if not self.wait(conf['interval'] * 60):
                return
```

2. Зарегистрируйте класс в `FarmManager.__init__` (`manager.py`), в списке
   площадок.
3. Если у площадки другая валюта, добавьте её цвет в `static/index.html`
   (`--s-mysite`); иначе будет общий цвет.
4. Напишите тесты: разбор страницы (HTML-фикстура в `tests/fixtures`), проход
   против поддельного сайта (как `FakeIndieGala` в `tests/test_farm.py`),
   `check()` и `preview()`.
5. Добавьте страницу в вики с блоком `<!-- settings:mysite --><!-- /settings -->`
   и выполните `env/bin/python scripts/build-wiki.py`.

**Чем пользоваться из `Platform`:**

- `self.settings()` — текущие настройки;
- `self.gate()`, `self.wait()`, `self.pause()` — ожидания, которые прерываются
  кнопкой «Стоп»;
- `self.ruleReason(conf, name, appid, owned)` — общие фильтры;
- `self.ownedGames(conf)` — библиотека Steam;
- `self.dailyLeft(conf)`, `self.closedFor(conf)` — лимиты и часы работы;
- `self.recordEntry()`, `self.recordWin()` — запись в историю;
- `self.manager.state.seen/markSeen` — что уже обработано;
- `self.info()`, `self.warn()` — журнал;
- `self.notify()` — Telegram;
- `self.balance`, `self.account`, `self.waitReason` — то, что видно на карточке.

## Проверки

```bash
pip install -r requirements-dev.txt
pytest                                         # все тесты, без сети и без cookie
ruff check .                                   # линтер, как в CI
env/bin/python scripts/build-wiki.py --check   # таблицы в вики не устарели
```

Синтаксис JavaScript панели можно проверить без Node.js на сервере:

```bash
docker run --rm -v "$PWD/steamgiftbot/farm/static":/w:ro node:22-alpine sh -c \
  "sed -n '/<script>/,/<\/script>/p' /w/index.html | sed '1d;\$d' > /tmp/p.js && node --check /tmp/p.js"
```

## Публикация вики

Страницы этой вики лежат в `docs/wiki/`. Перенести их в вики GitHub
можно скриптом:

```bash
scripts/publish-wiki.sh
```

Скрипту нужен доступ на запись к `<репозиторий>.wiki.git`. Ключи
развёртывания (deploy keys) к вики не подходят, нужен SSH-ключ аккаунта. А
саму вики нужно один раз создать на GitHub: вкладка **Wiki → Create the first
page**.
