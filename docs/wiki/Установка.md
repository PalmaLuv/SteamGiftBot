# Установка

У бота для командной строки и у фермы одна и та же установка.

## Проще всего: готовая программа для Windows

В [последнем релизе](https://github.com/PalmaLuv/SteamGiftBot/releases/latest)
лежат `BotFarm.exe` (ферма с панелью) и `SteamGiftBot.exe` (бот для командной
строки). Скачайте нужную в отдельную папку и запустите: `BotFarm.exe` один раз
спросит пароль панели и откроет её в браузере. Python и Git для этого не нужны.
Проверить, что файл не подменён: `certutil -hashfile BotFarm.exe SHA256` и
сравнить с `.sha256` из релиза.

Для Linux, macOS и сервера — установка из исходников ниже.

## Что нужно

- **Python 3.10 или новее.** Проверить версию: `python3 --version`.
- **Git**, чтобы скачать проект и потом обновлять его.
- **Для фермы** — компьютер или сервер, который не выключается: Linux (лучше
  всего), Windows или macOS. Хватит самого слабого мини-ПК: ферма почти всё
  время ждёт.

## Linux и macOS

```bash
git clone https://github.com/PalmaLuv/SteamGiftBot.git
cd SteamGiftBot
python3 -m venv env
source env/bin/activate
pip install -r requirements.txt
```

`env` — виртуальное окружение: зависимости ставятся в него, а не в систему.
Дальше любые команды запускайте либо после `source env/bin/activate`, либо
напрямую через `env/bin/python`, например `env/bin/python -m steamgiftbot.farm`.

## Windows

```powershell
git clone https://github.com/PalmaLuv/SteamGiftBot.git
cd SteamGiftBot
py -m venv env
env\Scripts\activate
pip install -r requirements.txt
```

Если нужна только SteamGifts, можно ничего не устанавливать и скачать готовый
`SteamGiftBot.exe` из [релизов](https://github.com/PalmaLuv/SteamGiftBot/releases/latest).
Подробнее — в [Бот для командной строки](Бот-для-командной-строки.md).

## Docker

Образ `ghcr.io/palmaluv/steamgiftbot` запускает бота для командной строки:

```bash
docker run --rm -e STEAMGIFTBOT_COOKIE=ваш_PHPSESSID ghcr.io/palmaluv/steamgiftbot
```

Ферму в Docker тоже можно запустить, переопределив команду. Параметр
`--data` переносит `farm.json`, `config.ini`, историю и логи в отдельную
папку. Её нужно смонтировать как том, иначе всё пропадёт вместе с
контейнером:

```bash
docker run --rm -it -v botfarm:/data --entrypoint python ghcr.io/palmaluv/steamgiftbot \
  -m steamgiftbot.farm --data /data --set-password

docker run -d --name botfarm --restart unless-stopped \
  -p 192.168.1.10:8092:8092 -v botfarm:/data \
  --entrypoint python ghcr.io/palmaluv/steamgiftbot \
  -m steamgiftbot.farm --data /data --host 0.0.0.0
```

Первая команда один раз задаёт пароль панели, вторая запускает ферму.

> Слушать `0.0.0.0` внутри контейнера можно: наружу порт выпускает только
> `-p`. Указывайте в `-p` адрес своей сети (`192.168.1.10:8092:8092`), а не
> один порт, иначе панель окажется доступна на всех адресах компьютера.

Вместо `--data` можно задать переменную окружения `BOTFARM_DATA`. Пароль
можно передать переменной `BOTFARM_PASSWORD`, тогда `--set-password` ничего
не спрашивает.

## Обновление

```bash
cd SteamGiftBot
git pull
env/bin/pip install -r requirements.txt
sudo systemctl restart botfarm      # если ферма работает как служба
```

Настройки, cookie и история хранятся в `farm.json`, `config.ini` и
`botfarm-state.json`. Эти файлы не входят в репозиторий, поэтому `git pull`
их не затрагивает.
