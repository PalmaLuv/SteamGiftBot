# Файлы и данные

Все файлы лежат в папке проекта, а если ферма запущена с `--data` — в
указанной папке.

| Файл | Что в нём | В git |
| --- | --- | --- |
| `farm.json` | хэш пароля панели, ключ подписи сессий, настройки фермы и каждой площадки (включая cookie), автозапуск | нет |
| `config.ini` | настройки SteamGifts и Telegram, общие с ботом для командной строки | нет |
| `botfarm-state.json` | история входов и выигрышей, счётчики по дням, уже просмотренные раздачи, служебные отметки | нет |
| `steamgiftbot-state.json` | о каких выигрышах SteamGifts уже сообщено | нет |
| `log/botfarm.log` | лог фермы, до 5 МБ, плюс три старых файла | нет |
| `debug/` | страницы, которые ферма не смогла разобрать (сейчас только OpiumPulses) | нет |
| `backups/` | архивы из `scripts/backup-farm.sh` | нет |

## farm.json

```json
{
  "web": {"password": {"salt": "…", "hash": "…"}, "secret": "…"},
  "settings": {"timezone": "Europe/Kyiv", "steam_api_key": "…", "…": "…"},
  "platforms": {
    "indiegala": {"autostart": true, "settings": {"cookie": "…", "sort": "smart", "…": "…"}},
    "steamfree": {"autostart": true, "connected": true, "settings": {}}
  }
}
```

Править вручную можно при остановленной ферме, но удобнее через панель. Если
удалить `web.secret`, все сессии панели закончатся.

## botfarm-state.json

По ключу на площадку:

| Поле | Что это |
| --- | --- |
| `entries` | последние 2000 входов: `time`, `name`, `cost`, `url` |
| `wins` | выигрыши: `time`, `name`, `url`, `status` (`""`, `received`, `activated`), `cdkey`, `redeem` |
| `daily` | счётчики по дням за 120 дней: `{"2026-11-20": {"e": входы, "s": траты, "w": выигрыши}}` |
| `seen` | до 5000 последних обработанных раздач, чтобы не входить в них повторно |
| `flags` | служебные отметки |
| `totalEntered`, `totalSpent` | счётчики за всё время |

Ключ `_farm` хранит служебные отметки самой фермы, например день последней
отправленной сводки.

Файл перезаписывается целиком после каждого изменения, атомарно: сначала
пишется во временный файл, потом подменяет старый. Поэтому даже внезапное
выключение не оставит его наполовину записанным.

## Перенос на другой компьютер

1. Остановите ферму.
2. Скопируйте `farm.json`, `config.ini`, `botfarm-state.json` и
   `steamgiftbot-state.json` в папку проекта на новом компьютере. Удобнее
   всего — архивом из `scripts/backup-farm.sh`.
3. Запустите ферму там. Cookie продолжат работать, если браузер, из которого
   они скопированы, не выходил из аккаунтов.
