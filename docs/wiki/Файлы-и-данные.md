# Файлы и данные

Все файлы лежат в папке проекта, а если ферма запущена с `--data` — в
указанной папке.

| Файл | Что в нём | В git |
| --- | --- | --- |
| `farm.json` | хэш пароля панели, ключ подписи сессий, настройки фермы и каждой площадки (включая cookie), автозапуск | нет |
| `config.ini` | настройки SteamGifts и Telegram, общие с ботом для командной строки | нет |
| `botfarm-state.json` | история входов и выигрышей, счётчики по дням, уже просмотренные раздачи, служебные отметки | нет |
| `farm.json.bak`, `botfarm-state.json.bak` | предыдущая удачная версия файла, на случай если текущий окажется испорчен; в `farm.json.bak` те же секреты, что и в `farm.json` | нет |
| `farm.json.corrupt-<время>`, `botfarm-state.json.corrupt-<время>` | испорченный файл, найденный при запуске: ферма откладывает его в сторону, а не затирает | нет |
| `steamgiftbot-state.json` | о каких выигрышах SteamGifts уже сообщено | нет |
| `accounts/<key>/` | файлы карточек SteamGifts в других [учётках](Несколько-учёток.md): свой `config.ini` с cookie и свой `steamgiftbot-state.json` | нет |
| `log/botfarm.log` | лог фермы, до 5 МБ, плюс три старых файла | нет |
| `debug/` | страницы, которые ферма не смогла разобрать (сейчас только OpiumPulses) | нет |
| `backups/` | архивы из `scripts/backup-farm.sh` | нет |

## farm.json

```json
{
  "web": {"password": {"salt": "…", "hash": "…"}, "secret": "…"},
  "settings": {"timezone": "Europe/Kyiv", "steam_api_key": "…", "…": "…"},
  "platforms": {
    "indiegala": {"autostart": true, "settings": {"cookie": "…", "sort": "smart", "…": "…"}},
    "steamfree": {"autostart": true, "connected": true, "settings": {}},
    "indiegala-2": {"autostart": true, "connected": true, "profile": "p2",
                    "account": "brother", "settings": {"cookie": "…"}}
  },
  "profiles": [{"id": "main", "name": "Основная"},
               {"id": "p2", "name": "Брат", "asf_bot": "Brother"}],
  "accounts": [{"key": "indiegala-2", "kind": "indiegala"}],
  "accountSeq": {"indiegala": 2},
  "profileSeq": 2
}
```

`profiles` — [учётки](Несколько-учёток.md), `accounts` — площадки, подключённые
в них сверх первой карточки сайта, `accountSeq` и `profileSeq` — последние
выданные номера: номер удалённой карточки не достаётся новой, чтобы не
смешалась история.

Править вручную можно при остановленной ферме, но удобнее через панель. Если
удалить `web.secret`, все сессии панели закончатся.

## botfarm-state.json

По ключу на площадку:

| Поле | Что это |
| --- | --- |
| `entries` | последние 2000 входов: `time`, `name`, `cost`, `url` |
| `wins` | выигрыши: `time`, `name`, `url`, `status` (`""`, `received`, `activated`), `cdkey`, `redeem` |
| `daily` | счётчики по дням за 120 дней: `{"2026-11-20": {"e": входы, "s": траты, "w": выигрыши}}` |
| `seen` | до 5000 последних обработанных раздач, чтобы не входить в них повторно |
| `flags` | служебные отметки |
| `totalEntered`, `totalSpent` | счётчики за всё время |

Ключ `_farm` хранит служебные отметки самой фермы, например день последней
отправленной сводки.

Файл перезаписывается целиком после каждого изменения, атомарно: сначала
пишется во временный файл, потом подменяет старый. Поэтому даже внезапное
выключение не оставит его наполовину записанным.

## Резервная копия и испорченные файлы

`farm.json` и `botfarm-state.json` записываются на диск до того, как
подменить старый файл, а старый остаётся рядом как `<имя>.bak`.

Если при запуске файл оказался испорчен (обрезан, не JSON), ферма
переименовывает его в `<имя>.corrupt-<дата>-<время>-<мс>`, берёт данные из
`<имя>.bak` и пишет предупреждение в `log/botfarm.log`. Когда резервной копии
нет, ферма начинает с пустого файла, но испорченный остаётся лежать рядом.
Отложенные файлы ферма не удаляет: когда разберётесь, удалите их сами.

Если файл есть, но прочитать его нельзя (нет прав, ошибка диска), ферма не
запускается и пишет почему: начать с пустого значило бы через два
сохранения затереть и сам файл, и его резервную копию.

`*.bak` и `*.corrupt-*` есть в `.gitignore` и `.dockerignore`: в них те же
пароль, ключ сессий и cookie.

## Перенос на другой компьютер

1. Остановите ферму.
2. Скопируйте `farm.json`, `config.ini`, `botfarm-state.json`,
   `steamgiftbot-state.json` и папку `accounts/` в папку проекта на новом компьютере. Удобнее
   всего — архивом из `scripts/backup-farm.sh`.
3. Запустите ферму там. Cookie продолжат работать, если браузер, из которого
   они скопированы, не выходил из аккаунтов.
